## Общие требования ко всем изображениям

1. **Цветовая палитра:**
   - Основной фон: #FFFFFF, #F7F4EE, #EFEEE9 (белый, бежевый, кремовый)
   - Акценты: #C9A55C (золото), #6BA37A (зелёный)
   - Вторичные: #EDE7DA (тёмный беж), #7E7AC8 (фиолетовый)

2. **Стиль:**
   - Светлый минимализм, без перегрузки деталями
   - Светлая премиум-палитра (белый + бежевый + золото)
   - Абстрактность, без конкретных фигур или текста
   - Деликатность, прозрачность элементов 8-20%

3. **Технические требования:**
   - Формат: WebP (основной), PNG (резерв)
   - Качество: 85%
   - Без водяных знаков
   - Без текста на изображениях
   - Оптимизация для web (быстрая загрузка)

4. **Атмосфера:**
   - Чистота, ясность, премиум-эзотерика
   - Духовность без религиозной специфики
   - Современность, не старомодность
   - Профессионализм, не китч

5. **Важно:**
   - Изображения должны работать как фоны для светлого отчёта
   - Текст отчёта (чёрный #1a1a1a) должен читаться поверх них
   - Использовать CSS `background-blend-mode: multiply` для интеграции
   - Проверять контрастность текста на фоне изображений (WCAG AA минимум)
   - Прозрачность фонов: 8-20% (не более!)

## Инструкции по генерации

1. Использовать Midjourney v6, DALL-E 3 или Stable Diffusion XL
2. Применять промпты на английском для лучшей точности
3. **Важно:** все фоны СВЕТЛЫЕ (белый/бежевый), не тёмные
4. Генерировать несколько вариантов, выбирать лучший
5. Постобработка в Photoshop/Figma: корректировка цвета, контраста
6. Сжатие в WebP через Squoosh или Sharp
7. Тестирование на разных устройствах (mobile, tablet, desktop)
8. Проверка: текст #1a1a1a должен читаться поверх фона

---

## Примечания

- Все изображения — СВЕТЛЫЕ фоны (белый/бежевый) для светлого дизайна отчёта
- Текст отчёта (#1a1a1a чёрный) должен читаться поверх фонов
- Использовать CSS `background-blend-mode: multiply` для интеграции
- Проверять контрастность текста на фоне изображений (WCAG AA минимум)
- Прозрачность фоновых элементов: 8-20% (не более!)
- Для PDF-версии фоны уже светлые — дополнительная корректировка не нужна
