## Общие требования ко всем изображениям

1. **Цветовая палитра:**
   - Основной фон: #0A0E0C, #0C1310, #0E2419
   - Акценты: #C9A55C (золото), #6BA37A (зелёный)
   - Вторичные: #8B7332 (приглушённое золото), #7E7AC8 (фиолетовый)

2. **Стиль:**
   - Минимализм, без перегрузки деталями
   - Тёмная премиум-палитра
   - Абстрактность, без конкретных фигур или текста
   - Деликатность, прозрачность элементов 10-30%

3. **Технические требования:**
   - Формат: WebP (основной), PNG (резерв)
   - Качество: 85%
   - Без водяных знаков
   - Без текста на изображениях
   - Оптимизация для web (быстрая загрузка)

4. **Атмосфера:**
   - Тайна, глубина, премиум-эзотерика
   - Духовность без религиозной специфики
   - Современность, не старомодность
   - Профессионализм, не китч

---

## Инструкции по генерации

1. Использовать Midjourney v6, DALL-E 3 или Stable Diffusion XL
2. Применять промпты на английском для лучшей точности
3. Генерировать несколько вариантов, выбирать лучший
4. Постобработка в Photoshop/Figma: корректировка цвета, контраста
5. Сжатие в WebP через Squoosh или Sharp
6. Тестирование на разных устройствах (mobile, tablet, desktop)

---

## Примечания

- Все изображения должны работать как фоны — текст отчёта должен читаться поверх них
- Использовать CSS `background-blend-mode: overlay` или `multiply` для интеграции
- Проверять контрастность текста на фоне изображений (WCAG AA минимум)
- Для PDF-версии использовать более светлые варианты фонов
