# Агенты — Описание

## 1. Accessibility Auditor
Аудит интерфейсов на WCAG 2.2 AA/AAA. Тестирует со screen reader (VoiceOver, NVDA, JAWS), проверяет клавиатурную навигацию, контрастность, focus management, ARIA-атрибуты. Ловит то, что автоматические сканеры пропускают.

## 2. AI Engineer
Разработка и продакшн ML-моделей. NLP, LLM/RAG, computer vision, рекомендательные системы. MLOps, bias detection, A/B тестирование моделей, оптимизация inference latency < 100ms.

## 3. Analytics Reporter
Трансформация сырых данных в бизнес-инсайты. Дашборды, RFM-сегментация, когортный анализ, юнит-экономика. Статистическая значимость (p-value, доверительные интервалы), прогнозирование.

## 4. API Tester
Функциональное, нагрузочное (k6) и security-тестирование API. OWASP API Security Top 10, rate limiting, контрактное тестирование, CI/CD quality gates. 95%+ покрытие.

## 5. Backend Architect
Проектирование масштабируемых бэкендов: микросервисы, event-driven, CQRS. Схемы БД с индексацией, API-дизайн (REST/GraphQL/gRPC), кэширование, security (OAuth 2.0, rate limiting, encryption).

## 6. Behavioral Nudge Engine
Адаптация софта под поведенческую психологию пользователя. Микроподталкивания, Pomodoro-style подход, снижение когнитивной нагрузки. Персонализация каналов и частоты коммуникации.

## 7. Code Reviewer
Ревью с фокусом на баги, безопасность, поддерживаемость и производительность. Приоритеты: 🔴 blocker, 🟡 suggestion, 💭 nit. Конкретные примеры исправлений, пояснение why.

## 8. Codebase Onboarding Engineer
Помогает новым разработчикам быстро разобраться в кодовой базе. Строит карту репозитория, трассирует execution paths, описывает архитектуру — только факты из кода, без домыслов.

## 9. Compliance Auditor
Подготовка к сертификациям (SOC 2, ISO 27001, HIPAA, PCI-DSS). Gap assessment, evidence collection, политики безопасности, контрольные процедуры. Аудит начинается до внешнего аудитора.

## 10. Content Creator
Контент-стратегия для мультиплатформенных кампаний. Блоги, видео, подкасты, соцсети. Редакционные календари, brand storytelling, SEO-контент, репаблишинг.

## 11. Database Optimizer
Оптимизация PostgreSQL: EXPLAIN ANALYZE, индексы (B-tree, GiST, GIN, partial), N+1 detection, connection pooling (PgBouncer). Zero-downtime миграции, безопасные DDL.

## 12. Design Implementer
Вёрстка дизайна из скриншотов в чистый HTML/CSS/JS (vanilla). Сравнивает скриншот → описание дизайна → код, правит расхождения (layout, цвета, типографика, тени, анимации). Стек: CSS custom properties, Grid/Flexbox, CSS-анимации.

## 13. DevOps Automator
CI/CD (GitHub Actions, GitLab CI), IaC (Terraform, CloudFormation), Docker/K8s. Blue-green/canary деплой, автоскейлинг, Prometheus/Grafana, security scanning в пайплайне.

## 14. Feedback Synthesizer
Сбор отзывов из множества каналов (поддержка, опросы, обзоры, соцсети). Сентимент-анализ, тематическое кодирование, приоритизация (RICE, MoSCoW, Kano). 90%+ точность тем.

## 15. Frontend Developer
React/Vue/Angular, TypeScript, Tailwind CSS. Core Web Vitals (LCP < 2.5s, FID < 100ms, CLS < 0.1), PWA, code splitting, WCAG 2.1 AA. Виртуализация списков, мемоизация.

## 16. Growth Hacker
Вирусный рост (K-factor > 1.0), CAC/LTV-оптимизация, A/B эксперименты, воронки. Product-led growth, реферальные программы, ретеншн (D7/D30/D90). 10+ экспериментов в месяц.

## 17. Incident Response Commander
SEV1-4 классификация, координация инцидентов (IC, Tech Lead, Comms, Scribe). Blameless post-mortem с 5 Whys. SLO/SLI, error budgets, runbooks, on-call ротации. MTTD < 5 мин.

## 18. Infrastructure Maintainer
Поддержание 99.9%+ uptime. Мониторинг (Prometheus/Grafana), бэкапы (шифрование AES-256), disaster recovery. Cost optimization, security hardening, IaC, patch management.

## 19. Minimal Change Engineer
Минимальный дифф — чинит только то, что сломалось. Никакого "while I'm here" рефакторинга. Одна строка фикса вместо 47 строк "улучшений". Медианный размер PR < 30 строк.

## 20. Performance Benchmarker
Нагрузочное тестирование (k6): load, stress, spike, endurance. Core Web Vitals, capacity planning, бутылочные горлышки (БД, сеть, код). SLA compliance, baseline before optimization.

## 21. Product Manager
Полный цикл продукта: discovery → PRD → roadmap → GTM → launch → measurement. RICE-приоритизация, OKR, юзер-стори, A/B тесты. Защита команды от scope creep.

## 22. Security Engineer
Threat modeling (STRIDE), secure code review, SAST/DAST/SCA. OWASP Top 10, JWT/токены, CSP, input validation, secrets management. CI/CD security gates. CVSS-классификация.

## 23. SEO Specialist
Техническое SEO (crawlability, indexation, Core Web Vitals), контент-кластеры, E-E-A-T. Cannibalization audit, structured data (FAQ, HowTo, Article), link building. Только white-hat.

## 24. Software Architect
Системный дизайн: DDD, bounded contexts, event storming. ADR (Architecture Decision Records). Trade-off analysis (consistency vs availability, coupling vs duplication). Эволюция без переписываний.

## 25. SRE (Site Reliability Engineer)
Надёжность как feature с бюджетом. SLO/SLI/error budgets, observability (RED-метрики), toil reduction. Progressive rollouts, chaos engineering, blameless культура.

## 26. Technical Writer
Документация для разработчиков: README, API reference, туториалы, migration guides. Divio-система (tutorial/how-to/reference/explanation). Docusaurus, MkDocs, OpenAPI. Docs-as-code в CI/CD.

## 27. Test Results Analyzer
Анализ результатов тестов: метрики покрытия, flaky-тесты, тренды, узкие места. Формирование actionable отчётов для команды.

## 28. Trend Researcher
Мониторинг 50+ источников: тренды, конкуренты, патенты, стартапы. TAM/SAM/SOM, Technology Readiness Level, сценарное планирование. Предсказание с горизонтом 6 месяцев.

## 29. UI Designer
Дизайн-системы: токены (цвета, типографика, отступы), компонентные библиотеки, тёмная тема, responsive. WCAG AA (4.5:1 контраст). CSS-переменные, transition, hover/active/focus состояния.

## 30. UX Architect
Технический фундамент для разработчиков: CSS-архитектура (Grid/Flexbox), theme toggle (light/dark/system), responsive breakpoints, spacing systems. Устраняет decision fatigue.

## 31. Workflow Architect
Проектирование полных деревьев workflow: happy path, все failure modes, timeout, partial failure, concurrent conflicts. Handoff contracts, observable states (customer/operator/DB/logs). Build-ready specs.
