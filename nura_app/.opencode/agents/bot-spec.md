# Промт для агента: Составить полную спецификацию Telegram-бота NURA

## Контекст

NURA — AI-продукт самопознания на базе "Матрицы Судьбы" (нумерология + 22 аркана Таро). Пользователь заходит в Telegram-бота, вводит дату рождения, получает бесплатный мини-разбор (через DeepSeek API), может купить полный AI-отчёт (HTML + PDF).

**Текущее состояние:** Базовая структура есть, но бот недоделан:
- /start → меню (4 кнопки)
- Расчёт матрицы → мини-разбор → пейволл
- Кнопки "Совместимость", "Инсайты", "Профиль" висят без обработчиков
- Нет чата с NURA
- Нет регистрации пользователя
- Нет платёжного флоу в боте
- Нет daily инсайтов
- Нет нормального профиля

## Задача

Составить **полный функциональный документ** бота на русском языке. Документ должен быть исчерпывающим — чтобы по нему разработчик мог написать весь код бота, не заглядывая в другие источники.

## Что должно быть в документе

### 1. Общая архитектура бота
- Стек: aiogram 3.13, FSM для состояний, Celery для тяжёлых задач, FastAPI для вебхуков
- Все callback_data, их формат и назначение
- Все FSM-состояния, переходы между ними
- Команды: /start, /menu, /profile, /help
- Middleware (регистрация пользователя, throttling, anti-flood)

### 2. Главное меню (после /start)

4 кнопки: ✨ Матрица, ❤️ Совместимость, 🌒 Инсайты, 👤 Профиль

**Приветственный текст** — эмоциональный, тёплый, интригующий. Не сухой как сейчас. Должен создавать желание нажать кнопку.

---

### 3. Блок "Матрица" ✨

**Флоу:**
1. Нажатие → бот просит дату рождения
2. Пользователь вводит ДД.ММ.ГГГГ
3. **Loading-анимация** — не просто текст, а:
   - Сначала: "✶ Считаю твою матрицу..."
   - Через 1 сек: "◈ Анализирую архетипы..."
   - Через 2 сек: "☯ Синхронизирую с энергиями..."
   - Через 3 сек: "✦ Готово!"
   (реализовать через редактирование одного сообщения с паузами)
4. Показ мини-разбора (5 блоков)

**Мини-разбор:**
- Красивое оформление: каждый блок в карточке с эмодзи
- Блоки:
  - 🎭 Главный архетип
  - ⚡ Сильная сторона
  - 🌊 Эмоциональный конфликт
  - 🔄 Паттерн отношений
  - 🔒 Денежный блок
- В конце: блок "Хочешь глубже?" → кнопка полного отчёта

**Тексты сообщений:**
- Запрос даты
- Ошибка валидации (неверный формат)
- Ошибка валидации (невозможная дата, типа 32.13.2020)
- Каждый шаг loading-анимации
- Каждый блок мини-разбора (шаблон с подстановкой из AI)
- Финальный блок с CTA

---

### 4. Блок "Совместимость" ❤️

**Флоо:**
1. Нажатие → объяснение фичи (2 даты = совместимость архетипов)
2. Запрос первой даты (ДД.ММ.ГГГГ)
3. Запрос второй даты
4. **Loading-анимация** (аналогично матрице, но про совместимость)
5. Результат:
   - 🎭 Архетип первого
   - 🎭 Архетип второго
   - 💞 Эмоциональная совместимость
   - ⚡ Зоны конфликтов
   - 🌟 Сильные стороны пары
   - 🔮 AI-рекомендация для отношений

**Монетизация:** Бесплатно показывать 2-3 блока (эмоциональная совместимость, зоны конфликтов). Полный разбор — по подписке 390₽/мес. Разовых покупок нет.

---

### 5. Блок "Инсайты" 🌒

**Что это:** Ежедневная персонализированная подсказка на основе архетипа пользователя.

**Флоу:**
1. Если пользователь НЕ ввёл дату рождения → "Сначала рассчитай матрицу"
2. Если дата есть → показ инсайта дня
3. Инсайт генерируется по архетипу (не через AI каждый раз, а по шаблонам, привязанным к 22 арканам)
4. Внизу: кнопка "Поделиться" (копировать текст) + "Получить ещё"

**Тексты:** Для каждого из 22 арканов — 5-7 вариантов инсайтов. В документе привести 2-3 примера + описать систему шаблонов.

**UX:** Сообщение должно выглядеть "утренним" — спокойным, глубоким, без спешки.

---

### 6. Блок "Профиль" 👤

**Что показывает:**
- Имя (из Telegram)
- Архетип (если матрица рассчитана)
- Статус подписки: бесплатный / есть отчёт / подписка
- Список отчётов (если есть) — ссылки на HTML
- Кнопка "Рассчитать матрицу" (если не рассчитана)
- Кнопка "Купить полный отчёт" (если только мини)
- Ссылка на PDF (если оплачен)

**Тексты сообщений:**
- Для пользователя без матрицы
- Для пользователя с мини-разбором
- Для пользователя с полным отчётом
- Для подписчика

---

### 7. Чат с NURA 💬

**Что это:** AI-собеседник, который знает матрицу пользователя и отвечает в контексте его архетипов.

**Как войти:**
- Кнопка в профиле: "💬 Чат с NURA"
- Если нет подписки/полного отчёта → пейволл
- Если есть доступ → открывается диалог

**Состояния FSM:**
- idle (вне чата)
- chatting (в диалоге)
- Выход из чата по команде /exit или кнопке "Выйти"

**Поведение AI:**
- System prompt: NURA, AI-проводник, знает матрицу пользователя, обращается на "ты", отвечает глубоко и тепло
- Контекст: последние 10 сообщений + матрица пользователя
- Кнопки в чате: "Выйти", "Очистить историю"

**Тексты:**
- Приглашение в чат
- Приветствие при входе (персонализированное)
- Заглушка "требуется подписка"

---

### 8. Платёжный флоу 💳

**Интеграция YooKassa:**
1. Пользователь нажимает "Оформить подписку"
2. Бот создаёт платёж через API → получает ссылку
3. Бот отправляет ссылку кнопкой (InlineKeyboardButton с URL)
4. Пользователь оплачивает в браузере
5. YooKassa присылает webhook на `/api/v1/payment/webhook`
6. API вебхук: проверяет платёж, обновляет статус в БД, запускает генерацию полного отчёта (Celery)
7. Когда отчёт готов — бот отправляет пользователю:
   - Ссылку на HTML-отчёт
   - Кнопку "Открыть отчёт"
   - PDF во вложении

**Тексты сообщений:**
- Ссылка на оплату (с предупреждением не закрывать)
- Платёж успешен → отчёт генерируется (loading)
- Отчёт готов → ссылка + PDF
- Ошибка оплаты
- Платёж уже был (если повторно нажимает)

**Совместимость:** Полный разбор совместимости доступен по подписке 390₽/мес. Разовых покупок нет.

---

### 9. Подписка (390₽/мес)

Включает:
- Ежедневные инсайты (автоматически в ЛС каждый день)
- Чат с NURA без ограничений
- Более глубокие интерпретации
- Все полные отчёты без доплат

**Механика:**
- Подписка через YooKassa (recurrent)
- Celery-beat: проверка истекающих подписок
- Уведомление: "Твоя подписка истекает через 3 дня"
- После истечения: downgrade до бесплатного

**Тексты:**
- Предложение подписки
- Преимущества подписки
- Напоминание об истечении
- Подписка оформлена
- Подписка истекла

---

### 10. Ежедневные инсайты (Celery-beat)

- Каждый день в 09:00 МСК отправлять подписчикам инсайт дня
- Инсайт = текст, привязанный к архетипу + случайный шаблон
- Если пользователь заблокировал бота — отписать от рассылки

**Текст:** Утреннее сообщение с:
- Приветствием по имени
- Инсайтом дня
- Мягким CTA (купить / открыть / вернуться)

---

### 11. Системные сообщения

- Ошибка: "Что-то пошло не так, попробуй ещё раз"
- Rate limit: "Слишком быстро, подожди немного"
- Регистрация: "Приятно познакомиться, {имя}!"
- /help: список команд и возможностей
- Кнопки заблокированы при ожидании ввода

---

## Требования к текстам

Все тексты бота должны быть:
- На русском, тёплые, эмоциональные, без эзотерического жаргона
- NURA обращается на "ты", как мудрый друг
- Никаких клише из типичных "матричных" ботов
- Каждое сообщение — маленький ритуал, а не просто информация
- Использовать редкие emoji (✶ ◈ ☯ ✦), не перегружать

Пример желаемого тона:
> "Твой архетип — Императрица. В тебе течёт энергия изобилия, но ты привыкла ставить других на первое место. А что, если этот поток развернуть к себе?"

Вместо сухого:
> "Главный архетип: Императрица. Сильная сторона: забота о других."

## Формат выдачи

Документ в формате Markdown, разделы с ##, подразделы с ###.
Каждый блок должен содержать:
- Полное описание логики
- Все тексты сообщений (дословно)
- Все callback_data
- Все FSM-состояния
- Переходы (что за чем идёт)
- Кнопки в каждом сообщении

HTML и PDF отчёты НЕ включать — они будут прорабатываться отдельно.
