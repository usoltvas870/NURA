# Skill: Context Budget

## Принцип
DeepSeek V4 Flash/Pro стоит денег. Каждый токен контекста — деньги. Минимизируй контекст без потери качества.

## Правила

### 1. Читай только нужное
- Не читай весь файл если нужна одна функция — читай конкретные строки (Read offset/limit)
- Не читай всю директорию — используй Glob/Grep для поиска
- Не тащи всю БД в контекст — только схему проблемной таблицы

### 2. Slim system prompt
- AGENTS.md — это ядро. Не дублируй его в каждом сообщении
- Не повторяй rules/lint инструкции — они уже в AGENTS.md

### 3. Завершай вовремя
- Когда задача решена — остановись. Не предлагай "улучшения" без запроса
- Не генерируй summary, не объясняй код — только код

### 4. Стратегия для больших задач
1. `Read` структуру директории → понять что где
2. `Grep` ключевые слова → найти релевантные файлы
3. `Read offset/limit` → читать только нужные секции
4. Edit → сделать правку
5. Stop

### 5. Agent routing
| Задача | Модель | Токенов |
|--------|--------|---------|
| CRUD, тест, багфикс | Flash | ~5K |
| Архитектура, 2+ модуля | Pro | ~15K |
| Сложный код, тупик | GLM-5.1 | ~30K |
| Тексты, копирайтинг | MiniMax/Kimi | ~4K |

Не используй Pro для простых правок — Flash справится за 1/10 цены.

### 6. Session management
- Не храни в контексте историю завершённых задач
- После /plan — удаляй план когда задача выполнена
- Используй hooks для сохранения контекста между сессиями
