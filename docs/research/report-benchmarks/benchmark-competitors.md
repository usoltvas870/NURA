## 6. Топ-5 рекомендаций (обновлено с учётом кросс-валидации)

### 1. 🔴 Радикально увеличить объём AI-текста (×3–5) — 8–12 часов

**Проблема:** Текущий output ~2600 слов. Конкуренты: 12000–18000+ слов.

**Решение:**
- `max_tokens`: 8000 → **32000** (DeepSeek Flash/V3 держит)
- В full_report.txt: явные требования «минимум 300–500 слов на поле»
- Разбить на **2 параллельных AI-запроса** через `asyncio.gather` (базовые секции + углублённые) — уже используется для kitchen layer
- Добавить требование: «Каждый ответ должен включать психологическую интерпретацию: какие убеждения формирует энергия, к каким ситуациям приводит, как изменить»

### 2. 🔴 Добавить «Психологические блоки и сценарии» — 4–6 часов

**Это главная фишка matrica-sudbyy.ru — то, за что их хвалят в отзывах.**

**Решение:**
- Новое AI-поле `psychological_blocks` (2000–3500 зн.): интерпретация энергий через психологические паттерны
- Не «аркан 15 = Дьявол = зависимости», а «энергия создаёт убеждение "я недостоин" → это приводит к саботажу успеха → вот как это изменить»
- Интегрировать в существующие секции: в каждую добавить блок «Почему это происходит и что делать»

### 3. 🔴 Развернуть «Жизненные периоды» + «Прогноз на год» — 6–8 часов

**Проблема:** Самая «худая» секция при максимальном спросе. Конкуренты дают «разделение по годам», «прогноз на год по сферам».

**Решение:**
- Таймлайн: HTML/CSS лента с иконками арканов по годам
- **Прогноз на текущий год**: по сферам (карьера, отношения, здоровье, деньги) — 1500–2500 зн.
- **Прогноз на 3 года**: таблица с ключевыми темами каждого года
- Ключевые возраста: визуальная шкала 0–80 лет
- Алгоритм расчёта аркана года уже описан в report-upgrade-plan.md

### 4. 🟡 Развернуть «Карту здоровья» + цветная визуализация — 4–6 часов

**Проблема:** matritca-sudbi.com показывает чакры с % зоны риска и списком органов. У NURA — только сырые данные.

**Решение:**
- AI-поле `health_analysis` (4000–6000 зн.): 7 чакр × 500–800 зн.
- Для каждой: название, состояние, причина дисбаланса, органы под управлением, практика восстановления
- Цветная HTML-визуализация чакр (как у matritca-sudbi.com)
- Расчёт % «зоны риска» на основе данных матрицы

### 5. 🟡 «Насыщающие» элементы дизайна + пустые шаблоны для рефлексии — 4–5 часов

**Идея DeepSeek, которой нет ни у кого:** пустые страницы в конце отчёта для записей пользователя.

**Решение:**
- 2-3 страницы с заголовками «Мои инсайты», «Что я попробую на этой неделе», «Заметки»
- Pull-quote (цитата-выноска) в каждой секции
- Иконка секции (22 эмодзи/номера арканов)
- Мини-задание в конце каждой секции: «Что попробовать» — 1 предложение
- Разделительная полоса между секциями

## 12. Стратегия: симбиоз Матрицы и Таро

### 12.1 Почему это работает

Матрица судьбы и Таро — **одна система** (22 старших аркана), два интерфейса:

| | Матрица | Таро |
|---|---|---|
| Основа | 22 аркана | 22 аркана |
| Входные данные | Дата рождения (статично) | Дата + запрос (динамика) |
| Восприятие | «Кто ты» | «Что делать сейчас» |
| Частота потребления | Один раз | Ежедневно/еженедельно |
| Функция в продукте | Привлечение (разовая покупка) | Удержание (подписка) |

**Ключевой инсайт:** матрица закрывает вопрос «узнай себя», таро — «что делать дальше». Вместе они создают замкнутый цикл: пользователь узнал свои арканы → хочет работать с ними каждый день → подписывается на таро-ритуалы.

### 12.2 Продуктовая схема

```
                    Бесплатный тизер
                    (карта дня, мини-разбор, 5 сообщений)
                           │
            ┌──────────────┼──────────────┐
            ▼                              ▼
     Матрица судьбы                  Таро-ритуалы
      (разово, 890 ₽)                 (подписка, 390 ₽/мес)
     └─ Полный отчёт (30-50 стр.)   └─ Ежедневная карта дня
     └─ Kitchen-слой                └─ Еженедельный расклад (3 карты)
     └─ Блок «Твоя карта дня»       └─ AI-расклад по вопросу
     └─ Доступ навсегда             └─ Безлимитный AI-чат
                                    └─ Привязка к арканам матрицы (если куплена)
```

### 12.3 Таро-блок в HTML-отчёте матрицы

При покупке матрицы пользователь получает в отчёте блок «Твоя карта дня»:

- Аркан дня (по дате рождения + текущая дата)
- Короткая интерпретация с привязкой к главному архетипу пользователя
- Ниже: CTA «Хочешь получать карту дня каждый день? Подпишись на таро-ритуалы»

### 12.4 Конкурентный анализ по Таро

| Конкурент | Таро-расклады | Привязка к матрице |
|-----------|-------------|-------------------|
| matrica-sudby.ru | Есть «Таро расклады» как **отдельная** услуга | Нет |
| 22energy.ru | Нет | Нет |
| matrica-sudbyy.ru | Нет | Нет |
| matrix-profi.ru | Нет | Нет |
| matritca-sudbi.com | Нет | Нет |

**Вывод:** ниша «таро-расклады на основе личной матрицы» полностью свободна. Это зелёное поле.

### 12.5 Tone-of-voice: два режима

| | Матрица | Таро |
|---|---|---|
| Тон | Психологический проводник (текущий tone-of-voice) | Ритуальный, метафоричный |
| Запреты | Эзотерический жаргон — запрещён | Эзотерические термины — разрешены (аркан, расклад, карта) |
| Визуальный скин | Чёрный + зелёный + оранжевый | Тёмно-синий + золотой |
| В меню бота | «Моя матрица» | «Ритуалы дня» |
