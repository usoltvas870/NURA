## 5. Позиционирование NURA

### Текущее состояние
- **Заявлено:** 30-50 страниц
- **Фактически:** ~25-35 страниц (17 секций)
- **Цена:** 890 ₽
- **Сегмент:** средний+

### Проблема
NURA позиционируется между средним и премиум сегментом по цене, но по объёму соответствует среднему сегменту.

**matrix-profi.ru** предлагает **105-107 страниц за 1400 ₽** — это в 2.5-3 раза больше, чем у NURA, при разнице в цене всего 57%.

## 6. Рекомендации

### Вариант A: Увеличить объём отчёта (рекомендуется)

**Цель:** достичь 60-80 страниц

**Действия:**
1. Добавить P1 (Психологические блоки) — +5-7 стр.
2. Добавить P2 (Карта здоровья) — +5-7 стр.
3. Расширить Kitchen-слой на все секции — +10-15 стр.
4. Добавить фоновые изображения — +5-10% объёма
5. Увеличить объём AI-текстов (попросить больше деталей)

**Результат:** 60-80 страниц, обоснованная цена 890-1200 ₽

### Вариант B: Снизить цену

**Цель:** соответствовать объёму 30-40 страниц

**Действия:**
1. Снизить цену до 690-790 ₽
2. Позиционирование: "доступный полный отчёт"

**Результат:** конкурентная цена, но меньшая маржа

### Вариант C: Добавить премиум-тариф

**Цель:** создать два тарифа

**Действия:**
1. Базовый (890 ₽): 30-40 страниц, текущий состав
2. Премиум (1290-1490 ₽): 80-100 страниц, все секции + Kitchen + изображения

**Результат:** охват обоих сегментов, upsell
