## 2. Базовые операции

### 2.1 Свёртка числа до аркана (`sum_digits`)

Любое число > 22 сворачивается суммированием цифр рекурсивно, пока не окажется в диапазоне 1–22.

```
sum_digits(n):
    while n > 22:
        n = sum(int(d) for d in str(n))
    return n
```

Примеры:
- `sum_digits(25) = 2+5 = 7`
- `sum_digits(1995) = 1+9+9+5 = 24 → 2+4 = 6`
- `sum_digits(22) = 22` (22 не сворачивается — это Шут)

### 2.2 Разбор даты рождения (`parse_birth_date`)

Формат ввода: `DD.MM.YYYY` (строка).

```python
def parse_birth_date(date_str: str) -> tuple[int, int, int]:
    day, month, year = date_str.strip().split(".")
    return int(day), int(month), int(year)
```

## 3. Основные позиции матрицы (базовый квадрат)

Даны: **День** (`D`), **Месяц** (`M`), **Год** (`Y`).

```
        B (месяц)
         │
A (день) ─── E (центр) ─── C (год)
         │
        D (низ)

Диагонали:
  ↖↘  Линия неба    (духовное предназначение)
  ↙↗  Линия земли   (материальное предназначение)
```

### 3.1 Углы квадрата

| Позиция | Обозначение | Формула | Описание |
|---------|-------------|---------|----------|
| Левый угол (мужская энергия) | `A` | `sum_digits(day)` | Аркан дня рождения |
| Верхний угол (небо) | `B` | `sum_digits(month)` | Аркан месяца |
| Правый угол (женская энергия) | `C` | `sum_digits(sum(int(d) for d in str(year)))` | Аркан года |
| Нижний угол (земля) | `D` | `sum_digits(A + B + C)` | Сумма трёх углов |

### 3.2 Центр (главный архетип)

| Позиция | Обозначение | Формула | Описание |
|---------|-------------|---------|----------|
| Центр | `E` | `sum_digits(A + B + C + D)` | Сумма всех четырёх углов |

### 3.3 Производные зоны

| Зона | Формула | Описание |
|------|---------|----------|
| Зона талантов | `sum_digits(E + B)` | Врождённый дар, предназначение духа |
| Зона комфорта | `sum_digits(E + A)` | Зона отдыха, как человек восстанавливает силы |
| Портретная зона | `sum_digits(E + D)` | Как человека видят другие |

### 3.4 Кармический хвост

Тройка арканов, отражающая кармический долг из прошлых воплощений:

```
Кармический хвост = [D, E, B]
                     Низ, Центр, Верх
```

Значение позиций в кармическом хвосте:
- **D (низ)** — причина, что совершил в прошлой жизни
- **E (центр)** — следствие, как проявляется в этой жизни
- **B (верх)** — урок, что нужно осознать и исправить

## 4. Расширенные позиции (внутренний квадрат)

Внутренние точки образуются попарным сложением соседних углов:

```
    B
  F   G
A   E   C
  I   H
    D

F = sum_digits(A + B)   (верхне-левая внутренняя)
G = sum_digits(B + C)   (верхне-правая внутренняя)
H = sum_digits(C + D)   (нижне-правая внутренняя)
I = sum_digits(D + A)   (нижне-левая внутренняя)
```

### 4.1 Линия неба (духовное предназначение)

Диагональ ↖↘: прошлая жизнь → центр → денежный канал.

```
Линия неба = [F, E, H]
             [sum_digits(A + B), E, sum_digits(C + D)]
```

- **F** — кармический дар из прошлых жизней (что наработано)
- **E** — центр (как проявляется)
- **H** — денежный канал (карма благосостояния)

### 4.2 Линия земли (материальное предназначение)

Диагональ ↙↗: линия отца → центр → линия матери.

```
Линия земли = [G, E, I]
              [sum_digits(B + C), E, sum_digits(D + A)]
```

- **G** — мужской род, линия отца (родовые программы по отцу)
- **E** — центр (как проявляется)
- **I** — женский род, линия матери (родовые программы по матери)

### 4.3 Линия отношений

Горизонтальная ось партнёрства. Образуется из мужской и женской энергий.

```
Линия отношений = [A, E, C]
                  [Левый угол, Центр, Правый угол]
```

- **A** — как человек проявляет себя в отношениях (активная позиция)
- **E** — центр отношений (баланс/дисбаланс)
- **C** — как партнёра воспринимает (принимающая позиция)

Дополнительная точка отношений:
```
Точка отношений = sum_digits(A + C)
```
Отражает тип партнёра, которого притягивает человек.

### 4.4 Линия денег (финансовый канал)

Вертикальная ось материального потока.

```
Линия денег = [B, E, D]
              [Верхний угол, Центр, Нижний угол]
```

- **B** — источник дохода (духовный уровень — что отдаю миру)
- **E** — центр (денежное мышление)
- **D** — результат (материальный уровень — что получаю)

Ключевой аркан финансового канала:
```
Аркан денег = H = sum_digits(C + D)
```

## 6. Полный пример расчёта

**Дата рождения:** `15.08.1995`

### Шаг 1: Разбор

```
day = 15, month = 8, year = 1995
```

### Шаг 2: Углы

```
A (left)  = sum_digits(15) = 15                                    → 15 (Дьявол)
B (top)   = sum_digits(8)  = 8                                     → 8  (Сила)
C (right) = sum_digits(1+9+9+5) = sum_digits(24) = 2+4 = 6        → 6  (Влюблённые)
D (bottom)= sum_digits(15+8+6) = sum_digits(29) = 2+9 = 11         → 11 (Справедливость)
```

### Шаг 3: Центр

```
E (center) = sum_digits(15+8+6+11) = sum_digits(40) = 4+0 = 4     → 4  (Император)
```

### Шаг 4: Производные зоны

```
talent_zone   = sum_digits(4+8) = sum_digits(12) = 12              → 12 (Повешенный)
comfort_zone  = sum_digits(4+15) = sum_digits(19) = 19             → 19 (Солнце)
portrait_zone = sum_digits(4+11) = sum_digits(15) = 15             → 15 (Дьявол)
```

### Шаг 5: Кармический хвост

```
karmic_tail = [11, 4, 8] → [Справедливость, Император, Сила]
```

### Шаг 6: Внутренние точки

```
F (inner_f) = sum_digits(15+8)  = sum_digits(23) = 2+3 = 5         → 5  (Иерофант)
G (inner_g) = sum_digits(8+6)   = sum_digits(14) = 14              → 14 (Умеренность)
H (inner_h) = sum_digits(6+11)  = sum_digits(17) = 17              → 17 (Звезда)
I (inner_i) = sum_digits(11+15) = sum_digits(26) = 2+6 = 8         → 8  (Сила)
```

### Шаг 7: Линии

```
sky_line         = [5, 4, 17]   → [Иерофант, Император, Звезда]
earth_line       = [14, 4, 8]   → [Умеренность, Император, Сила]
relationship_line = [15, 4, 6]  → [Дьявол, Император, Влюблённые]
money_line        = [8, 4, 11]  → [Сила, Император, Справедливость]
relationship_point = sum_digits(15+6) = 21                          → 21 (Мир)
```

### Шаг 8: Итоговая матрица

```
birth_date: "15.08.1995"
center: 4        → Император
Матрица:
        8 (Сила)
   15 (Дьявол)  4 (Имп.)  6 (Влюб.)
        11 (Справедливость)
Кармический хвост: Справедливость → Император → Сила
```

def sum_digits(n: int) -> int:
    """Свернуть число до аркана (1–22)."""
    while n > 22:
        n = sum(int(d) for d in str(n))
    return n

    """Разобрать строку DD.MM.YYYY."""

## 9. Примечания по реализации

1. **22 = Шут** — не сворачивается. Число 22 остаётся как есть (это полноценный аркан).
2. **Все суммы сворачиваются через `sum_digits`** — промежуточные значения могут превышать 22, но результат всегда 1–22.
3. **Кармический хвост** интерпретируется справа налево: низ (причина) → центр (следствие) → верх (урок).
4. **Расширенные позиции (F, G, H, I) и линии** полностью реализованы в `MatrixService.calculate()`.
5. **Актуальная реализация**: `nura_app/core/services/matrix.py` → `MatrixService.calculate()` возвращает `MatrixData` со всеми позициями (углы, центр, зоны, кармический хвост, внутренние точки, линии, точка отношений).
