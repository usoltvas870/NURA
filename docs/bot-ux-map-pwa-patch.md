## Новый: Путь 13 — Связка аккаунтов PWA ↔ Telegram

### Флоу: пользователь переходит из PWA

Пользователь нажал «Подключить Telegram» в профиле PWA → перешёл по ссылке
`t.me/nura_bot?start=link_TOKEN`.

```
/start link_a3f8c291-...
       │
       │  Бот находит токен в Redis
       │  → связывает telegram_id с web-аккаунтом
       ▼
┌─────────────────────────────────────┐
│                                     │
│  ✅ Аккаунты связаны!               │
│                                     │
│  Теперь карта дня будет приходить   │
│  сюда, если ты не включила          │
│  уведомления в приложении.          │
│                                     │
│  Можешь вернуться в NURA.           │
│                                     │
├─────────────────────────────────────┤
│  🌐 Открыть в NURA                  │  ← open_pwa
├─────────────────────────────────────┤
│  🏠 В меню                          │
└─────────────────────────────────────┘
```

### Флоу: токен не найден или истёк

```
/start link_EXPIRED_TOKEN
       │
       │  Токен не найден в Redis (TTL 15 мин истёк)
       ▼
┌─────────────────────────────────────┐
│                                     │
│  Ссылка устарела.                   │
│                                     │
│  Вернись в приложение NURA          │
│  и запроси новую ссылку —           │
│  она действует 15 минут.            │
│                                     │
├─────────────────────────────────────┤
│  🌐 Открыть в NURA                  │
├─────────────────────────────────────┤
│  🏠 В меню                          │
└─────────────────────────────────────┘
```
