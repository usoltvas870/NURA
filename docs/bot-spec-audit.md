## Итоговая рекомендация

### Что менять в bot-spec (по порядку приоритета)

#### 🔴 Блокеры (надо исправить до любой реализации)

1. **§15.2 — Таблица арканов.** Полная замена на версию из `matrix-algo.md` §1:
   - Индексация 1–22 (не 0–21)
   - Эмодзи из matrix-algo, за исключением конфликтующих с tone-of-voice (`🔮` для Мага, `⚡` для Башни) — для них согласовать нейтральные
   - Убрать дубликат `🌀`

2. **§3.7 — Формат AI-ответа мини-разбора.** Привести к `MiniAnalysisResult` из `prompt-spec.md` §2.3:
   - 5 плоских строк: `main_archetype`, `core_strength`, `emotional_conflict`, `relationship_pattern`, `financial_block`
   - Убрать вложенные объекты `{name, number, text}`
   - Имя и номер архетипа брать из `matrix_calculate_full()`, а не из AI

3. **Запрещённые эмодзи в user-facing текстах.** Пройти по всем текстам bot-spec и заменить:
   - `🔮` → `✨` или `📖` (CTA-кнопки, §3.8, §4.8, §4.9, §7.2)
   - `⚡` → другой эмодзи для «сильной стороны» (§3.6, §4.3)
   - `🌟` → `✨` (§4.3, §4.8)
   - Учесть, что tone-of-voice §7 сам противоречив насчёт `✨` — сначала исправить tone-of-voice (убрать `✨` из запрещённых)

4. **§1.2 — Висячие callback_data.** Для каждого из 13 нереализованных колбэков убедиться, что spec корректен (не дублирует, не конфликтует). Приоритет реализации — §16.

#### 🟡 Важно (исправить во вторую очередь)

5. **§7.4 — System prompt чата.** Дополнить всеми переменными из `prompt-spec.md` §5.1.
6. **§3.6 — Мини-разбор (заголовки блоков).** Обновить эмодзи заголовков.
7. **§8.6 — Текст «отчёт готов».** Скорректировать «22 аркана» → точное описание содержимого.
8. **§14 — Модель User.** Сверить с `core/models/user.py`.
9. **Добавить перекрёстные ссылки** на `prompt-spec.md` §6 (формат `matrix_text`).
