## Новый §10 — Таро в PWA

### 10.1 Экран `/app/tarot`

Основной экран раздела таро в PWA. Доступен через нижний таббар.

**Структура экрана:**

```
┌─────────────────────────────────────┐
│  NURA                        👤     │  ← хедер + иконка профиля
├─────────────────────────────────────┤
│                                     │
│  🌒 Таро                            │
│                                     │
│  ┌───────────────────────────────┐  │
│  │  Карта дня — {дата}           │  │  ← бесплатно, всегда видна
│  │  {Аркан} · {Ключевая фраза}   │  │
│  │  {Интерпретация 2-3 строки}   │  │
│  └───────────────────────────────┘  │
│                                     │
│  Расклады:                          │
│                                     │
│  ┌─────────────────┐ ┌───────────┐  │
│  │ ✦ Неделя       │ │ ◈ Вопрос  │  │
│  │ 🔒 Подписка    │ │ 🔒 Подп.  │  │
│  └─────────────────┘ └───────────┘  │
│  ┌─────────────────┐ ┌───────────┐  │
│  │ ✶ Сферы жизни  │ │ ☯ Двойн.  │  │
│  │ 🔒 Подписка    │ │ 🔒 Подп.  │  │
│  └─────────────────┘ └───────────┘  │
│  ┌─────────────────┐ ┌───────────┐  │
│  │ 🌅 Портал      │ │ 👁 Да / Нет│  │
│  │ 🔒 Подписка    │ │ 🔒 Подп.  │  │
│  └─────────────────┘ └───────────┘  │
│                                     │
│  ┌───────────────────────────────┐  │
│  │  💎 Открыть все расклады      │  │  ← CTA подписки
│  │     390 ₽/мес                 │  │
│  └───────────────────────────────┘  │
│                                     │
├─────────────────────────────────────┤
│  ◈  │  🌒  │  💬  │  👤           │  ← нижний таббар
└─────────────────────────────────────┘
```

> **Примечание к реализации:** фактический PWA-экран таро использует **сетку фото-карт** с бейджами замочков 🔒 на недоступных раскладах и **sheet-based пейволл** (нижний шторка) вместо inline-пейволла. Сетка рендерится как CSS Grid из горизонтальных карточек с иконками, заголовками и кнопками блокировки/действия. Детали — в `docs/pwa-spec.md §10`.

### 10.2 Карта дня в PWA

- Показывается сразу при открытии `/app/tarot`
- Та же логика персонализации что в боте: `_personal_arcana_number(today, center_arcana)`
- Данные подгружаются через `GET /api/v1/tarot/daily-card`
- Под картой — кнопка «Поделиться» → Web Share API

**API endpoint:**

```json
GET /api/v1/tarot/daily-card
Response (DailyCardResponse): {
    "arcana_number": int,
    "arcana_name": str,
    "arcana_symbol": str,
    "key_phrase": str,
    "interpretation": str,
    "advice": str,
    "affirmation": str,
    "date_label": str,
    "user_archetype_name": str | null,
    "user_archetype_number": int | null
}
```

### 10.4 Подписка через PWA

Оформление подписки 390₽/мес — только через PWA (не в боте).

Экран в `/app/profile` → «Управление подпиской»:

```
POST /api/v1/web/subscribe
Body: { session_id: str }
Response: { payment_url: str }
```

После оплаты: YooKassa webhook → `process_webhook()` → `has_tarot = True` в БД.

### 10.5 Web Share для раскладов

После любого расклада в PWA — кнопка «Поделиться»:

```javascript
navigator.share({
    title: 'Мой расклад таро — NURA',
    text: `Расклад на неделю: ${arcanaNames.join(' · ')}`,
    url: 'https://nura-ai.ru/app/tarot'
});
```

Для совместимости — дополнительно кнопка «Поделиться в Telegram» с `tg://` ссылкой.
