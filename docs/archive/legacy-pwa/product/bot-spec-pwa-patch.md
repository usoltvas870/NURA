## Изменения в §1 — Общая архитектура

### 1.0 НОВЫЙ РАЗДЕЛ — Роль бота в архитектуре

Вставить перед §1.1 как первый подраздел:

```
## 1.0. Роль бота в архитектуре NURA

Telegram-бот — это канал привлечения и push-fallback, НЕ основной интерфейс продукта.

Основной интерфейс продукта — PWA на nura-ai.ru (см. docs/platform-strategy.md).

### Что бот делает
- Первый контакт: /start → мини-разбор → deep-link в PWA
- Виральные механики: share совместимости, реферальные ссылки
- Push-уведомления: карта дня для тех кто не установил PWA (fallback)
- Связка с PWA-аккаунтом через link-токен

### Что бот НЕ делает
- Не является основным местом работы с продуктом
- Не принимает оплату подписки 390₽/мес (только ссылку на PWA)
- Не показывает полный отчёт (только кнопку "Открыть в NURA")
- Не ведёт полноценный чат (максимум 3-5 сообщений → CTA в PWA)

### Обязательное правило для всех хендлеров
После каждого значимого действия бот ОБЯЗАН показывать кнопку перехода в PWA:

┌─────────────────────────────────┐
│ 🌐 Открыть в NURA               │  ← URL: https://nura-ai.ru/app?token=AUTH_TOKEN
├─────────────────────────────────┤
│ 🏠 В меню                       │
└─────────────────────────────────┘

Значимые действия: мини-разбор, покупка, привязка аккаунта, отчёт готов.
```

## Новый §16 — Интеграция с PWA

Добавить как новый раздел перед §17 (Виральные механики):

```
## 16. Интеграция с PWA

### 16.1. Deep-link после ключевых действий

После каждого из перечисленных событий бот ОБЯЗАН показывать кнопку перехода в PWA.
Это не опционально — это обязательный шаг для каждого хендлера.

| Событие | Текст CTA | URL |
|---------|-----------|-----|
| Мини-разбор получен | 🌐 Открыть в NURA | nura-ai.ru/app |
| Отчёт матрицы готов | 🌐 Открыть отчёт | nura-ai.ru/report/{token} |
| Расклад совместимости | 🌐 Смотреть в NURA | nura-ai.ru/app/tarot |
| Привязка аккаунта | 🌐 Открыть NURA | nura-ai.ru/app |
| После любой оплаты | 🌐 Открыть в NURA | nura-ai.ru/app |

### 16.2. Link-токен — привязка аккаунтов

Пользователь нажал "Подключить Telegram" в PWA → бот получает команду:
/start link_{TOKEN}

Хендлер в bot/handlers/start.py:

```python
async def handle_link_token(message: Message, token: str):
    # 1. Обратиться к API: GET /api/v1/web/check-link-token?token={TOKEN}
    # 2. Если токен валиден → получить user_id
    # 3. Проставить telegram_id в запись пользователя
    # 4. Отправить подтверждение
    text = (
        "✅ Аккаунты связаны!\n\n"
        "Теперь карта дня будет приходить сюда, "
        "если ты не разрешил уведомления в приложении."
    )
    await message.answer(text, reply_markup=open_pwa_keyboard())
```

### 16.3. Проверка link-токена на бэкенде

Новый endpoint `GET /api/v1/web/check-link-token`:
- Принимает token (UUID)
- Ищет в Redis: link_token:{TOKEN}
- Возвращает user_id если токен валиден
- Удаляет токен после использования (одноразовый)
- 404 если токен не найден или истёк (TTL 15 минут)

### 16.4. open_pwa_keyboard() — новая клавиатура

```python
def open_pwa_keyboard(url: str = "https://nura-ai.ru/app") -> InlineKeyboardMarkup:
    return InlineKeyboardMarkup(inline_keyboard=[
        [InlineKeyboardButton(text="🌐 Открыть в NURA", url=url)],
        [InlineKeyboardButton(text="🏠 В меню", callback_data="main_menu")],
    ])
```

Добавить в `bot/keyboards/main_menu.py`.
```

### 17.1 — Обновить share после совместимости

После результата совместимости показывать три кнопки:

```
┌─────────────────────────────────────┐
│ 📤 Поделиться в Telegram            │  ← share_compat_tg (tg://msg_url)
├─────────────────────────────────────┤
│ 🔗 Скопировать ссылку               │  ← share_compat_copy (копируем URL)
├─────────────────────────────────────┤
│ 🌐 Смотреть в NURA                  │  ← open_pwa (nura-ai.ru/app/tarot)
└─────────────────────────────────────┘
```

`share_compat_tg` формирует:
```python
tg_url = f"tg://msg_url?url={ref_url}&text={quote(share_text)}"
```

`share_compat_copy` отправляет реферальную ссылку текстом:
```
Скопируй ссылку и отправь другу:
{ref_url}
```
