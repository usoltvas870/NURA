# Legacy PWA archive

**STATUS: LEGACY — ARCHIVED / COMPATIBILITY ONLY**

Этот раздел сохраняет PWA-first product, architecture и acceptance материалы. PWA может продолжать работать для обратной совместимости, но не является основным клиентом и не управляет текущим roadmap.

Текущие sources of truth:

- [canonical product target](../../product/NURA_1_0_1_5_PRODUCT_SPEC.md);
- [current implementation status](../../implementation/current-status.md);
- [documentation authority router](../../README.md).

Документы `architecture/` разрешено использовать только для безопасной поддержки существующей PWA. Документы `product/` и `acceptance/` являются историей прежней модели.

## Содержимое

- `product/` — PWA-first strategy и product/UX patches.
- `architecture/` — web-auth/PWA implementation and compatibility contracts.
- `acceptance/` — исторический PWA launch checklist.

Окончательный deprecation срок PWA требует отдельного owner decision.
