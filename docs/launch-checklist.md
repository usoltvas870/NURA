## 11. Порядок запуска (рекомендуемый)

### Неделя 1 — Разблокировать деньги

```
День 1-2:
  → Вставить YooKassa credentials
  → Alembic миграции (has_matrix, has_tarot, compatibility_used, web_session_id)
  → Тест флоу оплаты end-to-end

День 3-4:
  → Миграция пользователей (grandfather clause)
  → Уведомление в боте об обновлении тарифов
  → Лендинг: Hero тексты + CTA кнопки

День 5-7:
  → Бот: deep-link в PWA после мини-разбора и покупки
  → Бот: карточка-картинка для share (Sprinт 1 виральных механик)
  → Реферальная ссылка + таблица referral_rewards
```

### Неделя 2 — PWA минимум

```
День 1-3:
  → manifest.json + иконки + iOS meta-теги
  → service-worker.js
  → Web Push backend (api/routes/push.py + web_push.py)
  → Alembic: has_pwa_push, push_endpoint, push_p256dh, push_auth

День 4-5:
  → Install UI: iOS инструкция + Android auto-prompt
  → Обновить send_daily_card: дедупликация TG vs Web Push
  → nginx.conf: manifest, SW, /app маршруты
  → Тест PWA на Android + iOS 16.4+
```

### Неделя 3-4 — PWA экраны (параллельно с апгрейдом отчёта)

```
  → /app главный экран
  → /app/tarot
  → /app/profile с управлением уведомлениями
  → Link-токен связка PWA ↔ Telegram
  → /app/chat
  → Подписка 390₽ через веб
  → Параллельно: report-upgrade-sessions.md шаги 1-7
```
