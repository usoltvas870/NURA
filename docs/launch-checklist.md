## 2. Миграция текущих пользователей

Сейчас модель: **390 ₽/мес = всё включено** (матрица + инсайты + чат).

Новая модель: **матрица 890 ₽ разово + таро-ритуалы 390 ₽/мес**.

| Задача | Часы | Приоритет |
|--------|------|-----------|
| **Grandfather clause**: все текущие premium-пользователи получают матрицу бесплатно (флаг `has_matrix=True`) и сохраняют подписку 390 ₽/мес на таро-ритуалы | 1 | 🔴 P0 |
| Автоматическая миграция: скрипт или миграция Alembic, проставляющая `has_matrix=True` для всех существующих premium | 0.5 | 🔴 P0 |
| Уведомление пользователей: сообщение в боте «Мы обновили тарифы. Твоя матрица теперь твоя навсегда. Подписка теперь открывает таро-ритуалы» | 1 | 🔴 P0 |
| Обработка оттока: мониторинг отписок в первые 2 недели после перехода | 1 | 🟡 P1 |
| **Итого миграция** | **3.5 часов** | |
