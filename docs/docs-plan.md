# План подготовки документации NURA

## Цель

Написать 4 недостающих spec-документа для полного покрытия код-базы. Каждый документ пишется своей моделью и своим агентом, в порядке, где выход одного документа — вход для следующего.

## Порядок и зависимости

```
matrix-algo.md ──→ prompt-spec.md ──→ report-spec.md ──┐
                                              │         │
tone-of-voice.md ────────────────────────────┘         │
                                                       ▼
                                              bot-spec-audit.md
```

- `matrix-algo.md` — база для всех. Без него нельзя написать промпты (неизвестны названия арканов) и отчёт (неизвестны поля)
- `prompt-spec.md` — зависит от matrix-algo (знает структуру данных матрицы)
- `report-spec.md` — зависит от prompt-spec (знает поля AI-ответа) и от tone-of-voice (знает тон)
- `tone-of-voice.md` — независим, можно писать параллельно с matrix-algo
- `bot-spec-audit.md` — финальный аудит, проверяет bot-spec на консистентность со всеми новыми spec'ами

## Документы

## График

```
День 1-2:   matrix-algo.md  ──╼━━━  tone-of-voice.md  (параллельно)
День 3-4:   prompt-spec.md
День 5-6:   report-spec.md
День 7:     bot-spec-audit.md  (проверка bot-spec по всем новым spec'ам)
```

- Документы 1 и 4 — параллельно (нет зависимостей)
- После них — документ 2
- Потом документ 3
- Финалом — аудит bot-spec

Каждый документ: написание → ревью → правки → commit.
После аудита — правки в bot-spec по diff-листу → финальный commit.
