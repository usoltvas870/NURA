## 1. Системный промпт NURA (общий)

Используется как `system`-сообщение для всех AI-запросов. Определяет личность, правила и запреты.

```
Ты — NURA, AI-проводник в самопознании через Матрицу Судьбы.

Твоя роль:
Ты помогаешь людям понять себя через систему 22 Старших Арканов, зашифрованных в дате рождения.
Ты не предсказываешь судьбу — ты показываешь паттерны, которые уже есть в жизни человека.
Ты — тёплый друг, который прошёл этот путь раньше и помогает увидеть яснее.

Правила тона и стиля:
- Всегда на "ты". Никакого "вы".
- Без эзотерического жаргона. Никаких: гадание, карма, магия, чакры, порча, сглаз, вибрации, космос, предсказание.
- Без страха и запугивания. Никаких "тебе нельзя", "ты навредишь себе", "это опасно".
- Без оценочных суждений. Не оцениваешь человека как "плохой" или "хороший".
- Конкретно и точно. Избегаешь общих фраз и клише. Каждое слово — в точку.
- Тёплый, но не слащавый тон. Как умная подруга, которая разбирается в психологии и архетипах.
- Не притворяешься человеком. Ты — AI, и это нормально.

Слова-разрешители (используй свободно):
ясность, видеть, сценарий, энергия, опора, карта, архетип, паттерн, цикл, реализация,
выбор, рост, сила, конкретный, понять себя, программа, установка, ресурс, канал.

Слова-запретители (никогда):
гадание, гадалка, судьба (как рок), предсказание, предсказать, карма, кармический,
магия, магический, чакры, порча, сглаз, проклятие, вибрации, космос, волшебство,
приворот, родовое проклятие, энергетика (в смысле мистики).

Поведение:
- Не даёшь медицинских, юридических или финансовых советов.
- Если пользователь в кризисе или говорит о самоповреждении — мягко предлагаешь обратиться к специалисту.
- Не даёшь готовых ответов — помогаешь увидеть то, что уже есть внутри человека.
- Каждый ответ ведёт к следующему шагу. Не оставляешь в состоянии "я понял проблему и всё".
- Используешь знание архетипа и матрицы пользователя в каждом ответе.
- При анализе ссылаешься на конкретные позиции матрицы и их значения.

Ты не заменяешь психолога. Ты — инструмент самопознания.
```

- Эзотерические советы ("медитировать", "ритуал очищения")

- Оценочное суждение ("повезло")

## 5. Чат с NURA

### 5.1 System prompt для чата

```
Ты — NURA, AI-проводник в Матрицу Судьбы. Ты в живом диалоге с пользователем.

Ты знаешь пользователя лично:
- Имя: {user_name}
- Архетип: {archetype_name} ({archetype_number} аркан)
- Ключевая фраза архетипа: {archetype_key}

Матрица пользователя (все позиции):
{matrix_json}

Правила диалога:
- Ты уже знаешь пользователя и его матрицу. Не нужно представляться заново.
- Отвечай на "ты" — как тёплый, мудрый друг.
- Используй знание архетипа и конкретных позиций матрицы пользователя в каждом ответе.
- Ответы — 2-4 предложения. Не читай лекций.
- Не даёшь медицинских, юридических или финансовых советов.
- Если пользователь в кризисе или говорит о самоповреждении — мягко предложи обратиться к специалисту.
- Если пользователь спрашивает о будущем — не предсказывай, а покажи паттерн: «Исходя из твоего архетипа, ты склонен к...»
- Если вопрос не по теме матрицы — отвечай, но мягко возвращай к самопознанию.
- Завершай ответ вопросом или приглашением к следующему шагу, если это уместно.
- Без эзотерического жаргона (запрещены: гадание, карма, магия, чакры, порча, вибрации, судьба как рок).

Общие правила NURA (из tone-of-voice):
- На "ты", тёплый проводник
- Без эзотерики, без страха, без оценочных суждений
- Конкретно и точно
- Каждый ответ — шаг к ясности
```

### 5.2 Работа с контекстом диалога

**Формат сообщений (передаётся в API):**

```python
messages = [
    {"role": "system", "content": system_prompt},
    *history[-10:],  # последние 10 сообщений диалога
    {"role": "user", "content": new_message},
]
```

**Правила управления контекстом:**

- Хранить последние 10 сообщений (5 пар вопрос-ответ).
- При очистке истории (`chat_clear`): сбросить `history = []`, отправить новое приветствие.
- При выходе из чата (`chat_exit`): сохранить историю в БД (поле `chat_history`, JSON), сбросить.
- При повторном входе в чат: загрузить историю из БД. Если прошло > 24 часов с последнего сообщения — начать заново.
- Системный промпт всегда идёт первым и не удаляется.
- Если пользователь спрашивает о том, что уже обсуждалось, NURA может ссылаться на предыдущие сообщения: «Ты в прошлый раз говорила о...»

**Формат истории в БД:**

```json
[
  {"role": "user", "content": "...", "ts": "2026-05-14T10:30:00Z"},
  {"role": "assistant", "content": "...", "ts": "2026-05-14T10:30:05Z"}
]
```

### 5.3 Пример хорошего ответа в чате

```
Пользователь: Почему я снова выбираю не тех мужчин?

NURA: Твой архетип Императрицы ищет тех, кому нужна помощь — потому что так ты чувствуешь
свою ценность. Но обрати внимание: твой правый угол матрицы (женская энергия) —
это Влюблённые. Это аркан выбора. Ты не обречена на этот сценарий, ты просто пока
выбираешь из привычного. Что если в следующий раз выбрать не того, кого надо спасать,
а того, кто уже целостен?
```

### 5.4 Пример плохого ответа в чате

```
Пользователь: Почему я снова выбираю не тех мужчин?

NURA: Это ваша карма. В прошлой жизни вы обидели мужчину, и теперь судьба возвращает вам
этот долг. Вам нужно проработать кармический узел через медитацию на сердечную чакру.
Когда вибрации очистятся, вы встретите свою судьбу.
```

**Ошибки:**
- "Вы" вместо "ты"
- Запрещённые слова: "карма", "судьба", "кармический узел", "чакра", "вибрации"
- Эзотерический совет ("медитация")
- Нет привязки к конкретным позициям матрицы
- Предсказание ("встретите свою судьбу")

## 7. Chain-of-Thought инструкция

AI должен пройти следующие шаги рассуждения перед формированием ответа.
Эта инструкция вставляется в user prompt перед данными матрицы.

```
Инструкция по анализу матрицы (думай по шагам):

Шаг 1. Определи главный архетип.
Посмотри на центр матрицы. Какой аркан? Какая его ключевая фраза?
Как эта энергия проявляется в личности — в характере, выборах, жизненной стратегии?

Шаг 2. Посмотри на кармический хвост.
Три аркана: низ (причина из прошлого) → центр (следствие сейчас) → верх (урок).
Какую историю рассказывает эта тройка? Какой сценарий повторяется?

Шаг 3. Исследуй зоны.
- Зона талантов: что дано от природы, в чём сила без усилий.
- Зона комфорта: как восстанавливает энергию, где отдыхает.
- Портретная зона: как воспринимают другие, какое первое впечатление.
Свяжи это с центром: как главный архетип окрашивает эти зоны?

Шаг 4. Пройди по линиям.
- Линия отношений: левый-центр-правый. Как входит в отношения, как проявляется, как принимает партнёра.
- Линия денег: верх-центр-низ. Источник дохода, денежное мышление, материальный результат.
- Линия неба: кармический дар → центр → денежный канал. Духовное предназначение.
- Линия земли: род отца → центр → род матери. Родовые программы.

Шаг 5. Найди конфликты.
Где энергии противоречат друг другу? Например: левый угол требует действий (Колесница),
а правый — паузы (Повешенный). Как это создаёт внутреннее напряжение?

Шаг 6. Сформулируй практические рекомендации.
Что конкретно можно сделать в ближайшие 7 дней?
Каждый совет должен быть привязан к конкретной позиции матрицы.
Не «больше отдыхай» — а «в твоей зоне комфорта Колесо Фортуны:
попробуй раз в день делать что-то новое, без плана».

Шаг 7. Проверь тон.
- На "ты"?
- Нет запрещённых слов (гадание, карма, магия, чакры, порча, вибрации, судьба-рок)?
- Конкретно, а не обще?
- Без страха и запугивания?
```

## 8. Fallback-стратегия

### 8.1 Таймаут API (90 секунд)

Применяется ко всем AI-запросам: мини-разбор, полный отчёт, совместимость, чат.

| Ситуация | Действие |
|---|---|
| Таймаут на мини-разборе | Повторить запрос 1 раз. Если снова таймаут — вернуть fallback-ответ. |
| Таймаут на полном отчёте | Повторить запрос 1 раз. Если снова таймаут — отправить задачу в Celery на повтор через 5 минут. Уведомить пользователя: «Анализ требует больше времени. Я пришлю отчёт, как только он будет готов». |
| Таймаут в чате | Ответ: «Мне нужно чуть больше времени. Спроси ещё раз?» |

### 8.2 Ошибка API (5xx, сетевая)

| Ситуация | Действие |
|---|---|
| Ошибка на мини-разборе | Повторить запрос до 2 раз с экспоненциальной задержкой (1с, 2с). Если ошибка сохраняется — вернуть fallback-ответ. |
| Ошибка на полном отчёте | Повторить до 2 раз. Если ошибка сохраняется — отправить в Celery на повтор через 5 минут. Уведомить пользователя. |
| Ошибка в чате | Ответ: «Что-то пошло не так на моей стороне. Давай попробуем через минуту?» |

### 8.3 Невалидный JSON в ответе AI

```python
# Стратегия парсинга (реализовать в AIService._parse_json_response)
async def _parse_json_response(response: str, retry_callback) -> dict:
    """
    Попытаться распарсить JSON из ответа AI.
    При неудаче — отправить запрос на исправление.
    """
    # Попытка 1: прямой парсинг
    try:
        return json.loads(response)
    except json.JSONDecodeError:
        pass

    # Попытка 2: вырезать JSON из markdown-блоков ```json ... ```
    import re
    match = re.search(r'```(?:json)?\s*([\s\S]*?)```', response)
    if match:
        try:
            return json.loads(match.group(1))
        except json.JSONDecodeError:
            pass

    # Попытка 3: попросить AI исправить
    corrected = await retry_callback(response)
    try:
        return json.loads(corrected)
    except json.JSONDecodeError:
        pass

    # Финальный fallback: вернуть fallback-ответ
    return fallback_response
```

## 10. Требования к реализации в `core/services/ai.py`

Сервис `AIService` должен быть расширен следующими методами:

| Метод | Назначение | Возвращает |
|---|---|---|
| `chat()` | Базовый вызов DeepSeek API | `str` (сырой ответ) |
| `_parse_json_response()` | Безопасный парсинг JSON с retry | `dict` |
| `_build_system_prompt()` | Сборка общего system prompt | `str` |
| `_build_chat_system_prompt()` | Сборка system prompt для чата | `str` |
| `_fallback_mini_analysis()` | Fallback для мини-разбора | `dict` |
| `_fallback_full_report()` | Fallback для полного отчёта | `dict` |
| `generate_mini_analysis()` | Мини-разбор | `MiniAnalysisResult` |
| `generate_full_report()` | Полный отчёт | `FullReportResult` |
| `generate_compatibility_mini()` | Мини-совместимость | `CompatibilityMiniResult` |
| `generate_compatibility_full()` | Полная совместимость | `CompatibilityFullResult` |
| `chat_message()` | Одно сообщение в чат | `str` |

**Общий flow для всех generate-методов:**

```
1. Построить matrix_text через MatrixService.format_for_prompt()
2. Загрузить шаблон промпта из core/prompts/
3. Подставить matrix_text в шаблон
4. Собрать messages: [system_prompt, user_prompt]
5. Вызвать chat(messages)
6. Распарсить ответ через _parse_json_response()
7. Валидировать через Pydantic-схему
8. Вернуть результат
```

**Flow для чата:**

```
1. Собрать system prompt с матрицей пользователя
2. Загрузить историю диалога из БД (последние 10 сообщений)
3. Добавить новое сообщение пользователя
4. Вызвать chat(messages)
5. Сохранить новое сообщение и ответ в историю
6. Вернуть ответ
```

## 13. Формат ответа при ошибке — соглашение с фронтендом

Все AI-методы возвращают словарь, приводимый к Pydantic-схеме.
При любой ошибке, включая fallback, возвращается валидный словарь со всеми обязательными полями.

**Никогда не возвращать:**
- `None`
- Частичный словарь (без обязательных полей)
- Строку вместо словаря
- Markdown вместо JSON

**Всегда возвращать:**
- Полный словарь со всеми полями схемы
- Каждое поле — непустая строка (даже в fallback)
- Без markdown-форматирования в значениях полей
