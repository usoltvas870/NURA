> **STATUS: MIXED — TEMPORARY, NOT AUTHORITATIVE**

> Карта содержит current, legacy и future UX. До разделения в Stage 2B сверяйте каждый путь с [canonical spec](product/NURA_1_0_1_5_PRODUCT_SPEC.md) и [current status](implementation/current-status.md).

**Легенда:**
```
→  переход по кнопке / callback
⇒  системный переход (автоматически)
✎  пользователь вводит текст
═══ граница экрана телефона
```

## Путь 5: Совместимость

Совместимость работает по лимитной модели — не отдельный платный продукт:

```
❤️ Совместимость
       │
       ▼
┌─────────────────────────────────────┐
│  Проверка доступа                   │
│  has_matrix? compatibility_used?    │
│  has_tarot?                         │
└────────────────┬────────────────────┘
                 │
    ┌────────────┼──────────────────────────────┐
    ▼            ▼                              ▼
has_matrix=F  has_matrix=T               has_tarot=T
             AND used=F                  (безлимит)
             (первый расклад)
```

### Ветка A: Нет матрицы → пейволл матрицы

```
❤️ Совместимость
       │
       ▼
┌─────────────────────────────────────┐
│                                     │
│  ❤️ Совместимость                   │
│                                     │
│  Введи дату рождения любого         │
│  человека — я разберу вашу          │
│  совместимость по матрицам.         │
│                                     │
│  Доступно с покупкой Матрицы        │
│  судьбы.                            │
│                                     │
├─────────────────────────────────────┤
│  💎 Купить Матрицу — 890 ₽          │
├─────────────────────────────────────┤
│  🏠 В меню                          │
└─────────────────────────────────────┘
```
