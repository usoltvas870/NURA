# План доработки платного отчёта NURA

> Составлен на основе: `исследование рынка.md`, `report-spec.md`, текущего отчёта и кода.

---

## Диагноз текущего состояния

Текущий отчёт (8 секций текста) даёт **базовый уровень**, сопоставимый с бесплатными сервисами
конкурентов. До платного продукта за 690 ₽ он **не дотягивает**. Конкуренты продают PDF-отчёты за
1500–5000 ₽ и включают значительно больше разделов.

### Что уже есть (хорошо)
- 8 секций: архетип, сильные, тень, отношения, деньги, ошибки, конфликты, циклы
- 7-дневные рекомендации
- Качественный AI-текст (конкретный, с привязкой к позициям матрицы)
- Адекватный дизайн (dark theme, брендовые цвета)

### Что критически отсутствует
- **Родовые программы** — ключевой раздел, упомянутый во всех исследованиях рынка
- **Кармический хвост** — есть данные, но нет выделенного разбора
- **Предназначение** — линия неба не разбирается отдельно
- **Прогнозирование периодов** — нет вообще
- **Развёрнутая визуализация матрицы** — только 3×3 без линий и подписей
- **Резюме/ dashboard** — нет сводной страницы

### Что есть в данных, но не используется в шаблоне
Код вычисляет (`MatrixService.calculate`), но НЕ передаёт в шаблон:
- `inner_f`, `inner_g`, `inner_h`, `inner_i` (внутренние точки)
- `sky_line`, `earth_line` (линии неба/земли)
- `relationship_line`, `money_line` (явные массивы)
- `relationship_point` (точка отношений)
- `arcana_names` (названия арканов для всех позиций)

## План доработки: 4 фазы

### Фаза 1: Новые секции (ценностное ядро)

Добавить 4 раздела, которые превращают отчёт из «базового» в «глубокий»:

#### 1.1 Кармический хвост — глубокий разбор
**Данные:** `karmic_tail = [bottom, center, top]` (уже есть в данных)
**Содержание:**
- Низ (причина из прошлого) — какой сценарий тянется
- Центр (следствие сейчас) — как проявляется в этой жизни
- Верх (урок) — что нужно осознать и трансформировать
- Практический вывод: как выйти из кармического цикла

**AI:** новое поле `karmic_tail_analysis` в `FullReportResult`
**Промпт:** добавить в `full_report.txt` и `cot_instruction.txt`

#### 1.2 Родовые программы (линия отца + линия матери)
**Данные:** `earth_line = [father_line, center, mother_line]` (есть в расчёте, не передаётся в шаблон)
**Содержание:**
- Линия отца — какие программы, установки, сценарии унаследованы по мужской линии
- Линия матери — по женской линии
- Как родовые программы влияют на текущую жизнь
- Что взять из рода, что трансформировать

**AI:** новое поле `ancestral_programs` в `FullReportResult`
**Данные:** добавить `earth_line` в `matrix_raw` в `_process_full_report()`

#### 1.3 Предназначение (линия неба + зона талантов)
**Данные:** `sky_line = [inner_f, center, inner_h]` (есть, не передаётся)
**Содержание:**
- Кармический дар (F) — что наработано в прошлых жизнях, духовный ресурс
- Как центр направляет этот дар
- Денежный канал (H) — как предназначение монетизируется
- Конкретные профессиональные ниши и векторы развития

**AI:** новое поле `life_purpose` в `FullReportResult`
**Данные:** добавить `sky_line`, `inner_f`, `inner_h`, `talent_zone` в `matrix_raw`

#### 1.4 Прогнозирование жизненных периодов
**Данные:** матрица позволяет вычислять циклы по годам
**Содержание:**
- Текущий возраст и его архетипическая энергия
- Ключевые возрастные периоды: 17–25, 25–33, 33–40, 40–50, 50+
- Ближайший год — детальный аркан года с рекомендациями
- 3-летний прогноз

**AI:** новое поле `life_forecast` в `FullReportResult`
**Нужен алгоритм:** расчёт аркана года по дате рождения (см. доп. раздел ниже)

#### 4.3 Алгоритм «Аркан года»
```python
def calculate_year_arcana(birth_date: date, target_year: int) -> int:
    """Вычисляет аркан для конкретного года жизни."""
    age_at_birthday = target_year - birth_date.year
    return sum_digits(age_at_birthday)
```
Нужно добавить в `MatrixService` и передавать в промпт.
