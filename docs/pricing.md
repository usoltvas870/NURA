## 1. Продуктовая линейка (целевая)

NURA продаёт **три продукта** через одну точку входа — Telegram-бота:

| Продукт | Тип оплаты | Цена | Что внутри |
|---------|-----------|------|-----------|
| **Бесплатный тизер** | Бесплатно | 0 ₽ | Карта дня (без матрицы), мини-разбор (5 зон), 5 сообщений AI-чата |
| **Матрица судьбы** (полный отчёт) | Разовый платёж | **890 ₽** | Полный HTML/PDF отчёт (30-50 стр., 21+ секций), доступ навсегда, kitchen-слой, **1 расклад совместимости навсегда** |
| **Таро-ритуалы** (подписка) | Ежемесячно | **390 ₽/мес** | Ежедневная карта дня с привязкой к матрице, еженедельный расклад 3 карты, AI-расклад по вопросу, безлимитный AI-чат, **безлимитные расклады совместимости** |

### Воронка

```
Бесплатная карта дня (generic, без матрицы) → мини-разбор
        ↓
Покупка матрицы (890 ₽) → получает персонализированную карту дня в отчёте
        ↓
«Хочу каждый день» → подписка на таро-ритуалы (390 ₽/мес)
```

### Ключевые правила

1. **Подписка на таро работает и без покупки матрицы** — иначе сужаем воронку. Без матрицы ритуалы строятся на аркане дня по дате рождения. С матрицей — на полном наборе 22 арканов из отчёта.
2. **Матрица — навсегда.** Купил один раз → доступ не отзывается.
3. **В HTML-отчёте матрицы** — встроенный блок «Твоя карта дня» как тизер подписки на таро-ритуалы.

## 3. Логика совместимости

Совместимость — **не отдельный платный продукт**, а benefit, встроенный в существующие тарифы.

| Уровень | Совместимость |
|---------|--------------|
| Бесплатно | ❌ недоступна |
| Матрица 890 ₽ | ✅ 1 расклад навсегда |
| Таро 390 ₽/мес | ✅ безлимит пока активна подписка |

**Сценарии использования:**
- Партнёр (муж/жена) — разовая потребность → покрывает Матрица
- Друг, коллега, новый знакомый — повторяющаяся потребность → мотивирует подписку на Таро
- **Виральный механизм:** пользователь делает расклад на друга → друг видит результат → переходит в бота

**Логика проверки в боте:**
1. `has_matrix=False` → пейволл: купи Матрицу 890 ₽
2. `has_matrix=True AND compatibility_used=False` → доступно (первый расклад) → после использования: `compatibility_used=True`
3. `has_matrix=True AND compatibility_used=True AND has_tarot=False` → пейволл: подпишись на Таро
4. `has_tarot=True` → безлимит

## 4. Рыночное обоснование цен

### Матрица (разово 690–990 ₽)

| Конкурент | Цена за 1 отчёт |
|-----------|----------------|
| matrica-sudby.ru | 580 ₽ |
| matrica-sudbyy.ru | 590 ₽ |
| 22energy.ru | 100–499 ₽ |
| matritca-sudbi.com | 490 ₽ |
| matrix-profi.ru | 1400 ₽ |

NURA при 890 ₽: в рынке, но с уникальными фичами (AI-интерпретация, kitchen-слой, карта дня в отчёте, страницы рефлексии).

### Таро-ритуалы (подписка 390 ₽/мес)

| Конкурент | Что дают за деньги |
|-----------|-------------------|
| Онлайн-таро (любой сервис) | 1 расклад = 100–500 ₽ |
| Таролог (человек) | 1 консультация = 2000–5000 ₽ |
| **NURA** | **30 раскладов/мес на основе личной матрицы** = 390 ₽ |

Рыночный якорь: 30 раскладов × 100 ₽ = 3000 ₽. NURA даёт за 390 ₽. Цена воспринимается как сверхвыгодная.
