## Сводка изменений

### 1. `frontend/pwa-install.js` — полная переработка

**Удалено:**
- `isAndroid()` — заменено на `detectScenario()`
- Жёсткая привязка к Android для показа баннера
- Статический `setTimeout(showInstallBanner, 3000)` только для Android
- Привязка `triggerAndroidInstall()` к HTML через onclick

**Добавлено:**
- `detectScenario(nav)` — чистая функция, принимает опциональный mock-navigator для тестирования. Возвращает: `'installed' | 'ios' | 'opera' | 'chromium' | 'unknown'`
- `buildBannerHTML(scenario)` — генерирует innerHTML баннера под конкретный сценарий
- `populateBanner(scenario)` — вставляет HTML в контейнер `#pwa-install-banner`
- `triggerInstall()` — новое имя для `triggerAndroidInstall()` (старое имя сохранено как alias в `NURA_PWA`)

**Логика инициализации:**
1. `detectScenario()` → определяет сценарий
2. `installed` → выход
3. `ios` → существующий iOS-модал (без изменений)
4. `opera` / `unknown` → `populateBanner()` + `setTimeout(showInstallBanner, 2500)`
5. `chromium` → `populateBanner()` без автопоказа. Баннер показывается **только** при срабатывании события `beforeinstallprompt`

**Ключевое архитектурное решение:** для `chromium` баннер populated сразу (DOM готов), но `display:flex` устанавливается только в обработчике `beforeinstallprompt`. Это гарантирует, что кнопка «Установить» появляется только когда есть реальный `deferredPrompt`.

## CSS-переменные, используемые в баннере

Баннер наследует тему через CSS-переменные из `theme.css`:
- `--bg-card`, `--bg-card-soft` — фон
- `--text`, `--text-m` — цвет текста
- `--terra` — акцентный цвет (кнопка «Установить», иконка меню)
- `--line` — границы
- `--r-sm` — скругление кнопок

Переключение светлой/тёмной темы работает автоматически.

## Безопасность и надёжность

- **Нет ложных кнопок «Установить»:** в Opera, Firefox и неизвестных браузерах кнопка действия отсутствует — только текстовая инструкция и кнопка закрытия
- **Dismissal через sessionStorage:** после закрытия баннер не показывается до конца сессии (новая вкладка = новая сессия)
- **Проверка installed во всех ветках:** `isPWAInstalled()` вызывается и в `initPWAInstall()`, и в `showInstallBanner()` — двойная защита
- **Деградация без JS:** если JS не загрузился — баннер `display:none`, пользователь ничего не видит, PWA можно установить через нативные средства браузера
- **Public API NURA_PWA** сохранён с обратной совместимостью (`triggerAndroidInstall` → alias для `triggerInstall`)
